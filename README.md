An entry for the [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) competition on make.fun: invent the most useless superpower in one line of at most 140 characters.

## The entry

> I can turn invisible, but only my left sock.

44 characters, 9 words, one line. Invisibility — a real superpower — limited to a single sock: it achieves absolutely nothing, and the picture of a hero concentrating hard while one sock quietly vanishes is the whole joke.

## How it works

`main.py` is a stdlib-only copier: it copies the pre-written `entry.txt` into the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), so the program's output is byte-identical on every run.
